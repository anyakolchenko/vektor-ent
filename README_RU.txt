ВЕКТОР — PWA для Android (исходный пакет)
==========================================

Что входит:
- мобильный интерфейс;
- тренировка по 7 предметам и выбору темы;
- режим без таймера и режим с таймером;
- тренировочный пробник на 120 заданий / 240 минут;
- неограниченное число подсказок;
- объяснения к ответам;
- история ошибок и статистика;
- сохранение прогресса на устройстве через localStorage;
- офлайн-кэш после первого успешного открытия.

ВАЖНО О БАЗЕ ЗАДАНИЙ
Это стартовая авторская база из 35 заданий для проверки приложения и начала тренировки.
Она НЕ является официальной базой НЦТ и пока недостаточна для качественной подготовки к ЕНТ.
Пробник технически набирает 120 вопросов повторением имеющихся заданий, поэтому повторы возможны.
Для реальной подготовки нужно отдельно расширить банк, добавить актуальные типы заданий и сверить
структуру/оценивание с действующей спецификацией НЦТ. Не воспринимайте текущий пробник как
полную копию официального ЕНТ.

КАК УСТАНОВИТЬ НА ANDROID
PWA устанавливается из браузера только с сайта, опубликованного по HTTPS (или localhost).
Сам ZIP напрямую на телефон как приложение не устанавливается.

Простой способ публикации:
1. Распакуйте архив на компьютере.
2. Загрузите содержимое папки Vector_PWA в новый репозиторий GitHub.
3. В GitHub откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку /(root), сохраните.
5. Дождитесь адреса вида https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/
6. Откройте этот адрес в Chrome на Android → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

Можно также опубликовать папку на любом статическом хостинге с HTTPS.

ЛОКАЛЬНЫЙ ЗАПУСК ДЛЯ ПРОВЕРКИ
Из папки проекта выполните:
  python -m http.server 8000
Затем откройте на компьютере http://localhost:8000
(для Android нужен доступный HTTPS-хостинг).

СОХРАНЕНИЕ
Прогресс хранится локально в браузере этого устройства. Очистка данных браузера может удалить его.
Синхронизации между телефоном и компьютером пока нет.

ФАЙЛЫ

app.js — логика и стартовая база заданий
manifest.webmanifest — параметры установки

icon.svg — иконка
